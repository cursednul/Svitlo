# Світло · веб-версія (PWA)

Статична PWA-версія застосунку **Світло**. Показує графік відключень ДТЕК на
**сьогодні, 00:00–24:00** для вибраної адреси, з підказками вулиць і будинків,
таймлайном, зворотним відліком і сповіщеннями.

## Що вміє

- пошук вулиці серед 2 536 вулиць Києва;
- підказки будинків із ДТЕК для вибраної вулиці;
- автоматичне визначення черги, якщо ДТЕК дає однозначну відповідь;
- графік тільки на сьогодні, у київському часі;
- вікна відключень, поточний стан, зворотний відлік, таймлайн 00:00–24:00;
- окремі нагадування до відключення та до включення;
- збереження адреси й останнього графіка в `localStorage`;
- встановлення на домашній екран як PWA;
- резервний режим: якщо пошук за адресою недоступний, можна вибрати чергу
  вручну, і графік буде взято з публічної копії ДТЕК.

## Запуск локально

Потрібен Node.js 18+.

```bash
cd svitlo-web
node serve.js
```

Відкрий `http://127.0.0.1:8080/` у Chrome. Для встановлення PWA потрібен
`localhost` або HTTPS.

## Публікація

Це звичайні статичні файли. Достатньо завантажити папку `svitlo-web` на
GitHub Pages, Netlify, Cloudflare Pages або будь-який статичний хостинг.
`serve.js` потрібен лише для локальної перевірки.

## Звідки дані

1. **Адресний пошук ДТЕК** — відкритий DTEK-проксі проєкту
   [`YuraSidorets/dtek-shutdowns-checker`](https://github.com/YuraSidorets/dtek-shutdowns-checker).
   Він відкриває сторінку ДТЕК у справжньому браузері й повертає будинки та
   сьогоднішній графік. Оскільки проксі дозволяє запити лише зі свого origin,
   браузерна версія звертається до нього через безкоштовний
   [Jina Reader](https://jina.ai/reader/) (`https://r.jina.ai/http://...`).
2. **Публічна копія графіка** — якщо адресний пошук не відповідає, можна
   вибрати чергу вручну. Дані беруться з
   [`Baskerville42/outage-data-ua`](https://github.com/Baskerville42/outage-data-ua)
   (`data/kyiv.json`).

Дані ДТЕК можуть змінюватися або тимчасово не віддаватися. Якщо пошук за
адресою не працює, застосунок запропонує ручний вибір черги.

## Обмеження PWA

- Сповіщення працюють, поки вкладка/PWA відкрита. Браузер не дає звичайній
  PWA планувати фонові сповіщення без push-сервера.
- Для пошуку адреси потрібен інтернет. Останній графік зберігається локально
  і показується з попередженням, якщо ДТЕК недоступний.
- Це веб-версія, а не заміна Android-застосунку з foreground-сервісом.

## Файли

- `index.html` — інтерфейс;
- `app.js` — логіка адрес, графіка, таймлайну й сповіщень;
- `streets.js` — локальний довідник вулиць Києва;
- `styles.css` — стилі;
- `manifest.webmanifest`, `sw.js` — PWA;
- `serve.js` — локальний статичний сервер.

## Оновлення довідника вулиць

`streets.js` згенеровано з публічного довідника ДТЕК станом на 29.10.2026.
Якщо ДТЕК перейменує вулиці, онови `streets.js` зі свіжого списку
`window.DisconSchedule.streets` або з `/api/streets` відкритого проксі.
